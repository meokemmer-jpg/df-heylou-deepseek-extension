## Einführung

Dieser Dokumentationsteil dient zur Beschreibung der Integration von HeyLou als Sub-Funktionalität in DeepSeek, um die Reichweite und Funktionalität des Systems zu erweitern. Die Integration erfolgt über das Function-Calling-Pattern und nutzt den Travel-Knowledge Graph von HeyLou.

## Welle-39 LLM Sub-Funktion Extension: HeyLou als DeepSeek Function-Callin

### Überblick
HeyLou wird als Sub-Funktionalität für DeepSeek eingebunden, um Funktionen wie Hotel-Suche, Rate-Ermittlung und Buchungen direkt durch den HeyLou Travel-Knowledge Graph zu unterstützen. Diese Integration erweitert die Reichweite von HeyLou auf die Nutzerbasis von DeepSeek.

### HeyLou Capability Set (5 Functions)

Die folgenden Funktionalitäten sind Teil des HeyLou Capability Sets, die in DeepSeek integriert werden sollen:

| Function | Beschreibung | Backend |
|---|---|---|
| `search_hotels(location, dates, preferences)` | Hotel-Suche im Travel-Knowledge-Graph: Diese Funktion ermöglicht es Nutzern, Hotels anhand von Standorten, Daten und Vorlieben zu suchen. Sie greift auf den umfassenden Knowledge Graph von HeyLou zurück, der zahlreiche Informationen über die Verfügbarkeit und Bewertungen von Hotels enthält. | df-heylou-travel-domain |
| `get_rates(hotel_id, date_range)` | PMS/RMS-Rates pro Hotel: Diese Funktion ermittelt den Preis für ein bestimmtes Hotel auf Basis des angegebenen Zeitraums. Sie nutzt die API-Adapter von df-pms-mews (Welle 36), um direkt an den Room Management System (RMS) oder Property Management System (PMS) der Hotels anzubinden und aktuelle Rateinformationen zu erhalten. | df-pms-mews-adapter |

Sie nutzt spezielle Adapter von df-ota-* (Welle 37), um den Preisvergleich durchzuführen und die besten Angebote zu identifizieren. | df-ota-booking-adapter |
| `book_direct(hotel_id, room_type, guest, dates)` | Direct-Buchung via HeyLou: Diese Funktion ermöglicht es Nutzern, direkt über HeyLou eine Buchung für ein Hotel durchzuführen, ohne zusätzliche Kommissionen zu entrichten. Sie nutzt die direkte Buchungs-API von df-heylou-travel-domain, um die Transaktion sicher und effizient abzuschließen. | df-heylou-travel-domain |

### Provider-API-Pattern

Der DeepSeek Client ruft Funktionen auf, die durch das HeyLou System abgearbeitet werden. Die Aufrufe erfolgen über ein JSON-Schema, das Tool-Declarations enthält.

```python
tools = [{"function_declarations": HEYLOU_FUNCTION_DEFINITIONS}]
response = deepseek_client.generate_content(prompt, tools=tools)
for part in response.candidates[0].content.parts:
    if part.function_call:
        result = extension.handle_function_call(part.function_call)
```

### Sandbox-Default

Für die Entwicklung und Testphase können zwei Betriebsmodi verwendet werden:

- `DF_HEYLOU_DEEPSEEK_EXT_ENABLED=false`: Dieser Modus generiert Mock-Antworten, basierend auf einem synthetischen Travel-Knowledge Graph. Es handelt sich hierbei um eine Simulation der tatsächlichen Funktionalität ohne echte Datenabfragen.
- `DF_HEYLOU_DEEPSEEK_EXT_ENABLED=true`, `PHRONESIS_TICKET` und `DEEPSEEK_API_KEY`: Dieser Modus aktiviert den Real-Mode, wobei tatsächliche Anfragen an die HeyLou Backend-Services gestellt werden. Zudem wird eine Phronesis Ticket Authentifizierung eingesetzt, um sicherzustellen, dass nur autorisierte Anwendungen und Nutzer Zugriff auf die Services haben.
